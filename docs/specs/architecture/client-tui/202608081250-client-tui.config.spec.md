# Config: Cliente TUI

> Nenhuma variável de ambiente nova no código sem estar aqui.
> Precedência definida em `202608081203-configuration`, RN-7.

## 1. Painel de plano

| Variável | Tipo | Default | Uso |
|---|---|---|---|
| `DCODE_PANEL_ENABLED` | booleano | `true` | Mostra o painel de plano. Desligado, o contador vai para a linha de status e nada se perde além da lista. |
| `DCODE_PANEL_WIDTH` | inteiro | `24` | Colunas do painel. Abaixo de `18` o texto do item quebra demais para ser útil; acima de `40` o fluxo fica estreito para diff. |
| `DCODE_PANEL_MIN_TOTAL_WIDTH` | inteiro | `100` | Largura total abaixo da qual o painel colapsa sozinho (RN-5). Em 80 colunas com painel de 24 sobram 56 para o fluxo, e diff em 56 colunas é ruim. Preferência explícita do usuário vence este colapso automático. |

## 2. Fluxo

| Variável | Tipo | Default | Uso |
|---|---|---|---|
| `DCODE_DIFF_CONTEXT_LINES` | inteiro | `3` | Linhas de contexto ao redor de cada trecho alterado. |
| `DCODE_DIFF_MAX_LINES` | inteiro | `40` | Teto por diff no fluxo. Excedido, trunca e informa quanto sobrou; a expansão mostra tudo. |
| `DCODE_TOOL_EXPAND_ERRORS` | booleano | `true` | Erro vem expandido (RN-3). Desligar recolhe tudo por igual e é quase sempre a escolha errada: falha precisa de atenção. |
| `DCODE_STREAM_MAX_LINES` | inteiro | `10000` | Linhas mantidas na rolagem própria do cliente. Como a tela alternativa abre mão do scrollback nativo (RN-1), este valor é o que resta — reduzir demais destrói a auditoria visual da sessão. |

## 3. Entrada

| Variável | Tipo | Default | Uso |
|---|---|---|---|
| `DCODE_INPUT_QUEUE` | booleano | `true` | Aceita digitação durante o turno (RN-8). Desligado, a entrada fica bloqueada até o turno terminar. |
| `DCODE_INPUT_QUEUE_MAX` | inteiro | `10` | Mensagens na fila. Atingido, recusa e avisa em vez de descartar em silêncio. |

## 4. Apresentação

| Variável | Tipo | Default | Uso |
|---|---|---|---|
| `DCODE_COLOR` | enum | `auto` | `auto`, `always`, `never`. `auto` respeita `NO_COLOR` e detecta terminal sem suporte. |
| `DCODE_UNICODE` | booleano | `auto` | Marcas `✓ ▸ ⊘ ●` e bordas. Terminal sem suporte cai em ASCII sem perder informação. |

> A degradação para ASCII precisa preservar a **distinção** entre estados de item do plano. Se `⊘` e `✓` virarem o mesmo caractere, bloqueio passa por concluído — o pior erro possível neste painel.

## 5. Constantes não configuráveis

| Constante | Valor | Motivo |
|---|---|---|
| Tela alternativa | sempre | RN-1; painel fixo exige controle total da tela. |
| Negar é o default do modal | sempre | RN-6; a ação segura é a de menor esforço. |
| Comando renderizado no modal | sempre | RN-6; descrição sem comando é consentimento cego. |
| Modal não exibe o plano | sempre | RN-7; aprovar plano não é aprovar fronteira. |
| `full-access` com destaque de alerta | sempre | É o único estado em que estar errado é perigoso. |
| Contagem regressiva no modal | sempre | Expirar nega; o usuário precisa saber que o relógio corre. |
| Item `blocked` mostra o motivo | sempre | RN-4; bloqueio sem causa visível é pior que nenhum. |
| Comando embutido vence o do usuário | sempre | Nome embutido é contrato `stable`. |
| Fila produz um turno | sempre | Um turno por sessão, RN-8 do protocolo. |
