# Config: Conjunto de Ferramentas

> Nenhuma variável de ambiente nova no código sem estar aqui.
> Precedência: config travada por administrador > flag > variável de ambiente > arquivo de config > default.

> `DCODE_MAX_TOOL_OUTPUT` é declarada em `202608072240-client-server-protocol.config.spec.md`, seção 4, e vale como teto global de saída de qualquer ferramenta. Os limites abaixo são **por ferramenta** e se aplicam antes dele.
>
> `DCODE_TOOL_TIMEOUT` e `DCODE_TOOL_PARALLELISM` são declaradas em `202608072335-agent-loop.config.spec.md`, seção 2, porque são propriedade do escalonamento, não das ferramentas.

## 1. Leitura

| Variável | Tipo | Default | Uso |
|---|---|---|---|
| `DCODE_READ_MAX_LINES` | inteiro | `2000` | Linhas devolvidas por `read` sem `Limit` explícito. Excedido, trunca e declara. Cobre a esmagadora maioria dos arquivos de código inteiros; acima disso, ler tudo raramente é o que se quer. |
| `DCODE_READ_MAX_LINE_LENGTH` | inteiro | `2000` | Corte por linha. Protege contra arquivo minificado, onde uma única linha consumiria a janela inteira. |

## 2. Busca

| Variável | Tipo | Default | Uso |
|---|---|---|---|
| `DCODE_GLOB_MAX_RESULTS` | inteiro | `1000` | Caminhos devolvidos por `glob`. Excedido, trunca e declara — o modelo refina o padrão. |
| `DCODE_GREP_MAX_MATCHES` | inteiro | `200` | Ocorrências devolvidas por `grep`. Baixo de propósito: busca que casa milhares de vezes é busca mal formulada, e devolver tudo gasta contexto sem informar. |
| `DCODE_RESPECT_GITIGNORE` | booleano | `true` | `glob` e `grep` ignoram o que o `.gitignore` ignora. Desligar faz `node_modules` e `vendor` entrarem no resultado, o que quase sempre é ruído. |

## 3. Escrita

| Variável | Tipo | Default | Uso |
|---|---|---|---|
| `DCODE_WRITE_ATOMIC` | booleano | `true` | Escrita por arquivo temporário no mesmo diretório seguida de `rename`. Desligar só faz sentido em sistema de arquivos que não suporta `rename` atômico, e aceita o risco de arquivo parcial. |
| `DCODE_EDIT_REQUIRE_READ` | booleano | `true` | Implementa a invariante read-before-edit (RN-3). **Desligar é fortemente desaconselhado** — é a única proteção contra o agente sobrescrever, em silêncio, trabalho feito em paralelo. Existe apenas para depuração de um caso muito específico. |

> `DCODE_EDIT_REQUIRE_READ=false` deveria disparar aviso em nível `warn` na inicialização, pelo mesmo critério de `danger-full-access` combinado com `never`.

## 4. Constantes não configuráveis

| Constante | Valor | Motivo |
|---|---|---|
| `edit` falha em match ambíguo | sempre | RN-4; escolher a primeira ocorrência acerta quase sempre e, quando erra, corrompe código em silêncio. |
| Ordenação de `glob` | alfabética | Ordem do sistema de arquivos varia por máquina e quebraria golden file. |
| Truncamento sempre declarado | sempre | RN-5; truncar em silêncio faz o modelo concluir com confiança sobre dados que não viu. |
| Saída de linha numerada em `read` | sempre | Dá a `edit` e ao modelo o mesmo referencial. |
| Código de saída não-zero em `bash` não é erro de ferramenta | sempre | O modelo precisa do código para decidir; transformar em erro esconde o sinal. |
| `Declare` sem efeito colateral | sempre | RN-6; a política decide antes de qualquer efeito. |
