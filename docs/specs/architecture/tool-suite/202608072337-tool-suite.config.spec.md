# Config: Conjunto de Ferramentas

> Nenhuma variável de ambiente nova no código sem estar aqui.
> Precedência: config travada por administrador > flag > variável de ambiente > arquivo de config > default.

> `DCODE_MAX_TOOL_OUTPUT` **não existe**. O teto de saída de ferramenta é constante em `tools.DefaultLimits()`; a chave foi removida em `202608110900` por nunca ter sido lida.
>
> `DCODE_TOOL_TIMEOUT` e `DCODE_TOOL_PARALLELISM` são declaradas em `202608072335-agent-loop.config.spec.md`, seção 2, porque são propriedade do escalonamento, não das ferramentas.

## 2. Busca

| Variável | Tipo | Default | Uso |
|---|---|---|---|
| `DCODE_SYMBOL_MAX_MATCHES` | inteiro | `200` | Ocorrências devolvidas por `symbol`. Mesmo teto de `grep`, e pelo mesmo motivo. |

## 3. Escrita

| Variável | Tipo | Default | Uso |
|---|---|---|---|
| `DCODE_EDIT_ECHO_DIFF` | enum | `multi` | Quando o diff volta ao **modelo** (RN-9). `never` devolve só a contagem. `multi` devolve em `replace_all` que afetou mais de uma ocorrência — o único caso em que o modelo não consegue derivar o resultado. `always` devolve em toda edição: custo alto no histórico append-only, útil para depurar um modelo que está editando errado. |

> `write` não tem modo e **nunca** devolve diff, em nenhum valor da chave. Não é economia: a informação seria exatamente o que o modelo acabou de ditar.

> `DCODE_EDIT_REQUIRE_READ` **não existe**, e portanto não existe o aviso que este parágrafo descrevia. A invariante read-before-edit é constante `true` em `tools.DefaultLimits()` — mais forte que uma chave que se pode desligar.

## 4. Constantes não configuráveis

| Constante | Valor | Motivo |
|---|---|---|
| `edit` falha em match ambíguo | sempre | RN-4; escolher a primeira ocorrência acerta quase sempre e, quando erra, corrompe código em silêncio. |
| Ordenação de `glob` | alfabética | Ordem do sistema de arquivos varia por máquina e quebraria golden file. |
| Truncamento sempre declarado | sempre | RN-5; truncar em silêncio faz o modelo concluir com confiança sobre dados que não viu. |
| Saída de linha numerada em `read` | sempre | Dá a `edit` e ao modelo o mesmo referencial. |
| Código de saída não-zero em `bash` não é erro de ferramenta | sempre | O modelo precisa do código para decidir; transformar em erro esconde o sinal. |
| `Declare` sem efeito colateral | sempre | RN-6; a política decide antes de qualquer efeito. |
| `write` nunca devolve diff ao modelo | sempre | RN-9; seria devolver o conteúdo que ele mesmo acabou de ditar. |
| Diff devolvido declara truncamento | sempre | RN-5; diff cortado em silêncio faz o modelo concluir sobre o que não viu, achando que viu tudo. |
| Nome buscado por `symbol` é escapado | sempre | RN-10; aceitar regex faria `symbol` ser `grep` com outro nome. |
| Resultado de `symbol` declara o limite textual | sempre | RN-10; resultado vazio parecendo completo é o pior modo de falha da busca. |
