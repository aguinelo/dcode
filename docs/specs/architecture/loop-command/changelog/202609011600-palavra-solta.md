# Palavra solta

**2026-09-01** — RN-9: `/loop <palavra>` que não nomeia pasta alguma é objetivo,
não caminho.

## A RN-8 não alcançava o caso mais simples

Escrita a regra de que objetivo sem pasta é qualificado, `/loop oi` continuou
respondendo:

```
could not open a session: invalid_input: loopcommand: read
/Users/…/dcode_test/oi/tasks.md: open /Users/…/oi/tasks.md: no such file or directory
```

Erro cru do daemon, caminho absoluto duas vezes, para quem digitou uma palavra.

## Por quê

O `specArgument` decide o que é caminho, e a primeira linha dele é:

```go
if len(words) == 1 {
    return true
}
```

Uma palavra só é **sempre** caminho. O comentário justifica: *"one word is what a
folder name looks like and the error names it when it is not there"*.

A justificativa tem uma metade certa e uma metade que não se sustentou. Certa:
uma palavra de fato parece nome de pasta. A que não se sustentou: o erro que ela
nomeia não é o erro do comando, é o do daemon lendo um arquivo — e é o pior tipo
de mensagem que este produto emite, porque conta o caminho absoluto da máquina de
quem escreveu, duas vezes, e não diz o que fazer.

Efeito: a RN-8 valia só a partir de duas palavras. `/loop cadastro de clientes`
era objetivo; `/loop cadastro` era uma pasta inexistente.

## A regra

Palavra solta que não nomeia nenhuma pasta **encontrada pela pesquisa** é prosa,
e vira objetivo qualificado.

O que decide é o **separador**. Quem escreveu `specs/hoem` quis um caminho, e
erro de digitação respondido com qualificação é erro de digitação escondido —
esse continua sendo erro. A distinção é a mesma que o `specArgument` já fazia
para frases; só não estava sendo feita para a palavra única.

O que vier depois da palavra pertence a ela, então `/loop cadastro clientes` é o
mesmo briefing mais curto.

## Onde a virada acontece

No `loopOne`, antes do laço que compara com as pastas encontradas. Esse laço só
sabe responder sobre pasta que existe; cair através dele era o que abria sessão
contra um caminho que nunca esteve lá.

## Invariantes

- `TestABareWordThatNamesNoFolderBecomesAGoal`
- `TestABareWordThatNamesAFolderStaysAPath`
- `TestAMistypedPathIsNotQualifiedAway`
- `TestLoopOneDivertsABareWordThatNamesNothing` — pelo `loopOne`, e visto
  vermelho sem a ligação.
