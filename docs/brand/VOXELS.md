# Voxel maps

Grid is 16×16. One character = one voxel.

| Char | Role | Colour |
|---|---|---|
| `^` | highlight | `#EFC066` |
| `#` | body | `#E0A030` |
| `-` | shadow | `#B87D1E` |
| `o` | eye | `#A8452A` |
