## en

- **Five spec families describe the code that runs.** A review found
  configuration, context-engine, agent-loop, behavior-definition and
  working-defaults describing a product that is not the one shipped: a
  `dcode config get` subcommand that does not exist, `allow_network = false`
  where the default is true, a `DCODE_COMPACT_AT` key that was never read, a
  repeat detector said to fire at three calls when it fires at five, a phase
  diagram in the family that says there is no phase machine, reminder kinds
  the code never had while six it emits were missing, and a family still
  calling itself unimplemented with its key and probe in production. Each
  family now follows the code and records the correction in its own
  changelog; nothing in the product changes, apart from one code comment in
  `internal/loop` that still said "three times".

## pt-BR

- **Cinco famílias de spec descrevem o código que roda.** Uma revisão achou
  configuration, context-engine, agent-loop, behavior-definition e
  working-defaults descrevendo um produto que não é o entregue: um subcomando
  `dcode config get` que não existe, `allow_network = false` onde o default é
  true, uma chave `DCODE_COMPACT_AT` que nunca foi lida, um detector de
  repetição dito disparar em três chamadas quando dispara em cinco, um
  diagrama de fases na família que diz não haver máquina de fases, tipos de
  lembrete que o código nunca teve enquanto faltavam seis que ele emite, e uma
  família ainda se dizendo não implementada com a chave e a sonda em produção.
  Cada família agora segue o código e registra a correção no próprio
  changelog; nada no produto muda, salvo um comentário de código em
  `internal/loop` que ainda dizia "three times".
